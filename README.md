# Case for a 1-probe shutter speed tester based on the hiroshootsfilm project

_This is my attempt to create a case/housing for the electronics and components for a 1-probe shutter speed tester._

## Project goals:
- A 3D printable case to house shutter speed tester electronics
- Learning git/github and sharing my result with other people

## Parts list:
- 1-probe shutter speed tester components are based on the hirshootsfilm project and can be found on the dedicated project site: https://projecthub.arduino.cc/hiroshootsfilm/shutter-speed-tester-for-film-cameras-8ffb04
- Prototype PCB 6x4cm
- 3x12 countersunk screws, 4 screws for the coover
- M2 screws, 4 screws to screw the PCB into the case
- 2.54mm Pitch Single Row Female PCB Socket Board Male Pin Header Connector For Arduino, to be soldered onto the PCB and for the Arduino Nano to be placed on to fit the USB opening in the case
